# Roadmap

## Prototype

- dwie listy SharePoint,
- eksport CSV,
- walidacja Python,
- KPI i Health Status,
- raport Excel,
- plik Power BI,
- JSON dla AI.

## Version 2

- więcej własnych makr i flow,
- Records Processed,
- automatyczne tworzenie rekordów miesięcznych,
- reminder flow,
- logger dla jednego flow i jednego procesu VBA.

## Version 3

- automatyczne pobieranie danych,
- trend miesiąc do miesiąca,
- rule-based anomalies,
- prognoza portfela.

## ML stage

Po spełnieniu warunków z `ml_readiness.json`:

- regresja czasu manualnego względem wolumenu,
- anomaly detection,
- forecast oszczędności,
- klasyfikacja ryzyka problemu,
- clustering automatyzacji.
