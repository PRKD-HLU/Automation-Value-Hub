# Prototype Demo Script

1. Pokaż dwie listy SharePoint.
2. Wyjaśnij różnicę między Clean Success, Rework, Failed i Retry.
3. Pokaż przesłane CSV w `data/input`.
4. Uruchom `pytest`.
5. Uruchom `python main.py --month 2026-08`.
6. Otwórz `data_quality_issues.csv` i pokaż wykryte ostrzeżenia.
7. Otwórz `automation_kpi.csv` i pokaż obliczone KPI.
8. Otwórz raport Excel.
9. Pokaż JSON dla AI i przykładowe podsumowanie.
10. Podłącz `automation_kpi.csv` do Power BI.
